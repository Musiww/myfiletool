# Project collaboration rules

- Make requested source and documentation changes locally, then report the changed files and verification results.
- Leave Git staging, commits, pushes, pull requests, and merges to the project owner. Do not perform these actions unless the owner explicitly changes this preference for the specific action.
- Read-only Git commands such as `git status`, `git diff`, and `git log` are allowed to inspect and explain the current state.
- Keep `DESIGN.private.md` and personal input or output files out of the public repository.
